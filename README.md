# ⚡ Dev.ai Studio

AI-powered coding assistant — Code लिखो, GitHub पर push करो, deploy करो।

## 🚀 Features

- **AI Chat** — Puter.js (100% free, no API key needed)
- **Code Editor** — Multi-file, syntax highlighting
- **GitHub Push** — Directly files push करो
- **Deploy** — Vercel, Netlify, Render, Railway, Cloudflare
- **APK Build** — Codemagic integration
- **Dark/Light Theme**
- **Firebase** — Chat history, settings sync

## ⚙ Setup

1. GitHub Pages enable करो: Settings → Pages → Branch: main
2. App open करो → Login with Puter
3. Settings में tokens add करो
4. Coding शुरू करो!
